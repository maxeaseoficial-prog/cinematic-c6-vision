# C6 Cinematic Vision

OBJETIVO

Criar do zero uma landing page premium, cinematográfica, moderna e altamente visual inspirada no universo do C6 Bank.

Este projeto é um CONCEPT / REDESIGN VISUAL para apresentação e gravação de vídeo.

NÃO é uma reconstrução funcional do banco.

Não implementar:

- backend;

- Supabase;

- banco de dados;

- autenticação;

- login real;

- abertura real de conta;

- APIs bancárias;

- pagamentos;

- operações financeiras;

- painel administrativo;

- CMS.

O foco absoluto é:

DIREÇÃO DE ARTE + FRONTEND + RESPONSIVIDADE + ANIMAÇÕES + QUALIDADE VISUAL.

A página deve parecer um redesign profissional de altíssimo nível para um grande banco digital brasileiro.

O resultado final será usado principalmente para gravar um vídeo navegando e fazendo scroll pela landing page.

3. IDENTIDADE VISUAL

==================================================

PALETA PRINCIPAL:

- preto profundo;

- grafite;

- carvão;

- branco;

- off-white;

- cinzas sofisticados;

- AZUL como cor principal de destaque.

REGRA INEGOCIÁVEL:

NÃO USAR ROXO.

Qualquer referência fornecida que possua roxo deve ser reinterpretada usando AZUL.

O azul deve aparecer de forma controlada em:

- iluminação;

- links;

- CTAs;

- pequenos detalhes;

- linhas;

- hover;

- reflexos;

- elementos selecionados;

- pequenos gradients;

- glow muito sutil.

Não transformar a página inteira em azul.

A base deve continuar predominantemente:

PRETO + BRANCO + GRAFITE.

Evitar:

- neon excessivo;

- cyan exagerado;

- glow em todo elemento;

- gradientes multicoloridos;

- arco-íris;

- excesso de transparência;

- glassmorphism em tudo.

==================================================

4. TIPOGRAFIA

==================================================

Usar sans-serif moderna, premium e extremamente legível.

A tipografia deve possuir forte presença editorial.

HEADLINES:

- grandes;

- medium/semi-bold;

- line-height relativamente apertado;

- tracking refinado;

- poucas palavras;

- bastante espaço negativo.

BODY:

- menor;

- excelente legibilidade;

- cinza quando estiver sobre preto;

- largura de linha controlada.

Usar no máximo 1 ou 2 famílias tipográficas.

Não usar fontes extravagantes.

No desktop, algumas headlines podem ocupar uma parte significativa da viewport.

Utilizar clamp() ou estratégia responsiva equivalente para evitar que títulos quebrem no mobile.

11. ANIMAÇÃO DO HERO

==================================================

As animações devem ser sofisticadas e discretas.

NO CARREGAMENTO:

- headline entra suavemente;

- texto secundário aparece em sequência;

- CTAs aparecem;

- cartões entram com pequeno deslocamento;

- opacity + transform.

NO SCROLL:

- cartões podem mover alguns pixels;

- pequena rotação;

- parallax;

- background typography pode mover em velocidade diferente;

- iluminação pode variar muito discretamente.

Evitar:

- bouncing;

- animação infantil;

- objetos girando infinitamente;

- partículas;

- blobs pulando;

- efeitos de videogame;

- animações constantes sem função.

Se usar Framer Motion, GSAP ou equivalente, manter implementação performática.

Respeitar:

prefers-reduced-motion.

38. MICROINTERAÇÕES

==================================================

Implementar microinterações sofisticadas.

LINKS:

- mudança sutil de cor;

- underline animado discreto quando apropriado.

BOTÕES:

- hover suave;

- pequena alteração de background;

- pequena alteração de contraste;

- movimento máximo de aproximadamente 1-2px quando fizer sentido.

CARDS:

- scale extremamente pequeno;

- mudança de iluminação;

- zoom discreto da imagem.

HEADER:

- transição suave no scroll.

SCROLL:

- reveal progressivo;

- parallax apenas em elementos selecionados.

NÃO adicionar:

- cursor personalizado;

- partículas;

- sons;

- loading screen desnecessária;

- mouse trail;

- blobs animados;

- efeitos chamativos sem função.

45. PERFORMANCE

==================================================

Como a landing será usada para gravação de vídeo, scroll e animações precisam ser extremamente fluidos.

Evitar:

- filtros CSS muito pesados;

- vídeos gigantes em background sem necessidade;

- dezenas de listeners de scroll;

- animações causando layout thrashing;

- assets gigantes sem otimização;

- bibliotecas desnecessárias.

Priorizar:

transform

opacity

nas animações.

Lazy-load apenas imagens abaixo da dobra.

O hero/LCP não deve depender de lazy-loading.

Definir dimensões das imagens para reduzir CLS.
